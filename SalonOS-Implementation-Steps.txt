EXECUTION NOTES FOR mimo v2.5
================================================================================

HOW TO USE THIS FILE:
1. Read this file at start of each session
2. Scan for first [0] - that's where you start
3. Complete the task, change [0] to [1]
4. Continue until session ends or tasks complete
5. Next session repeats from step 1

Session Guidelines:
1. One task at a time - Complete one task before moving to next
2. Build after each phase - Verify solution compiles
3. Test after each module - Run existing tests, add new ones
4. Commit frequently - Small, focused commits
5. Document decisions - Update README with architecture choices

File Naming Conventions:
- Projects: SalonOS.{ModuleName}.csproj
- Entities: {EntityName}.cs (PascalCase)
- DTOs: {EntityName}Dto.cs
- Validators: {EntityName}Validator.cs
- Controllers: {EntityName}Controller.cs
- Services: {EntityName}Service.cs

Dependency Direction:
  API -> Infrastructure -> Modules -> Shared
  Modules -> Shared (never between modules)

Multi-Tenancy Rules:
1. TenantEntity - Base class for all tenant-owned entities
2. Global Query Filters - Automatic tenant scoping
3. TenantContext - Resolved from JWT + Membership
4. Never trust client - Server always validates tenant

Money Rules:
1. Always use Money type - Never raw numbers for currency
2. Two columns - Amount (long) + Currency (string)
3. No floating point - Integer minor units only
4. No coercion - Different currencies throw exception
