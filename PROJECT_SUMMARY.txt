# خلاصه پروژه SmartSalon / SalonOS

این پروژه یک پلتفرم SaaS چندمستأجری (Multi-Tenant) برای مدیریت سالن‌های زیبایی است که تحت نام تجاری SalonOS شناخته می‌شود. پروژه شامل سه بخش اصلی است.

================================================================================
                         ساختار کلی پروژه
================================================================================

SmartSalon/
├── SmartSalon/SmartSalon/     ← مونولیت قدیمی (ASP.NET Core 9)
├── src/                        ← مونولیت مدلار جدید (DDD)
│   ├── SalonOS.Api/
│   ├── SalonOS.Shared/
│   ├── SalonOS.Infrastructure/
│   └── Modules/
│       ├── Identity/
│       ├── Booking/
│       ├── Catalog/
│       ├── Inventory/
│       └── Marketplace/
├── smart_salon_app/            ← اپلیکیشن موبایل Flutter
└── tests/

================================================================================
                  اپلیکیشن موبایل (Flutter)
================================================================================

- ۱۳ صفحه: Splash, Login, Register, OTP, Home, Salon Detail, Booking,
            Guest Booking, Profile, Notifications, Appointment List
- مدیریت State: Flutter Riverpod (StateNotifier)
- معماری Clean Architecture: Domain / Data / Presentation
- زبان فارسی و RTL: تقویم شمسی (shamsi_date)، رنگ‌بندی فارسی
- امکانات: جستجوی سالن، رزرو نوبت، امتیازدهی، سیستم وفاداری
            (Bronze / Silver / Gold / Diamond)، نوتیفیکیشن

================================================================================
              بک‌اند قدیمی: مونولیت SmartSalon (ASP.NET Core 9)
================================================================================

--- مدل‌های داده (Entity Framework Core + SQL Server) ---

| مدل                    | توضیح                                                           |
|------------------------|-----------------------------------------------------------------|
| ApplicationUser        | کاربر با نقش‌ها: SuperAdmin, SalonManager, Artist, Client       |
| Salon                  | سالن با فیلدهای نام، آدرس، مختصات جغرافیایی، تم رنگی، VIP     |
| Artist                 | آرایشگر با نوع قرارداد (حقوق ثابت/اجاره خط/اجاره اتاق)        |
| SalonService           | خدمات سالن (دسته‌بندی، قیمت، مدت زمان)                          |
| Appointment            | نوبت با ۶ وضعیت: Pending, Confirmed, InProgress, Completed,    |
|                        | Cancelled, NoShow                                                |
| Notification           | نوتیفیکیشن داخل اپ با انواع info/success/warning/error         |
| ServicePackage         | پکیج خدمات اشتراکی                                             |
| SalonPackageSubscription | اشتراک فعال سالن روی پکیج                                     |

--- کنترلرها و APIها ---

| کنترلر              | مسیر                | اندپوینت‌ها                                              |
|----------------------|---------------------|----------------------------------------------------------|
| AuthController       | api/auth            | Register, Login, Profile, Logout, ChangePassword         |
| SalonsController     | api/salons          | CRUD + جستجو + فیلتر VIP + صفحه‌بندی                     |
| ArtistsController    | api/artists         | CRUD + آپلود عکس + گزارش عملکرد                          |
| ServicesController   | api/services        | CRUD خدمات سالن                                          |
| AppointmentsController| api/appointments   | رزرو، تأیید، تکمیل، لغو، امتیازدهی، دریافت اسلات خالی  |
| NotificationsController| api/notifications | لیست، خواندن، حذف، تعداد خوانده‌نشده                      |

--- سرویس‌ها (Business Logic) ---

| سرویس               | وظیفه                                                         |
|----------------------|---------------------------------------------------------------|
| AuthService          | احراز هویت با JWT (۳۰ روز اعتبار)، رمز عبور ۸+ کاراکتر       |
| SalonService         | مدیریت سالن‌ها با صفحه‌بندی، جستجو و فیلتر                   |
| ArtistService        | مدیریت آرایشگران + گزارش عملکرد روزانه + آپلود عکس            |
| ServiceService       | CRUD خدمات با بررسی وابستگی قبل حذف                            |
| AppointmentService   | مدیریت نوبت‌ها: اسلات‌یابی، رزرو با ۳۰٪ پیش‌پرداخت،          |
|                      | لغو با محدودیت ۲ ساعته، امتیازدهی میانگین                     |
| NotificationService  | ارسال و مدیریت نوتیفیکیشن‌ها                                  |
| ReminderService      | سرویس پس‌زمینه ساعتی: یادآوری SMS از طریق MeliPayamak        |
| SmsService           | ارسال پیامک از طریق اپراتور MeliPayamak با ۳ بار تلاش مجدد  |

--- قابلیت‌های کلیدی بک‌اند قدیمی ---

- پیش‌پرداخت ۳۰٪ خودکار هنگام رزرو
- سیستم امتیازدهی وفاداری: به ازای هر ۱۰,۰۰۰ تومان ۱ امتیاز
- یادآوری خودکار SMS برای نوبت‌های نزدیک
- Rate Limiting: ۱۰ درخواست/دقیقه برای Auth، ۶۰ درخواست/دقیقه برای API
- Swagger/OpenAPI مستندسازی

================================================================================
          بک‌اند جدید: مونولیت مدلار SalonOS (DDD + Multi-Tenant)
================================================================================

--- ماژول‌ها ---

| ماژول        | وظیفه                                                        |
|--------------|---------------------------------------------------------------|
| Identity     | احراز هویت، مدیریت Tenantها، عضویت کاربران                  |
| Booking      | رزرو نوبت با Domain Events (BookingCompleted, BookingCancelled)|
| Catalog      | کاتالوگ خدمات با Option Groups                                |
| Inventory    | مدیریت موجودی با دفتر کل (Stock Movement) و رویداد کمبود     |
| Marketplace  | بازار قالب‌های خدمات و لایسنس پکیج‌ها                        |

--- Shared Kernel ---

- TenantEntity: کلاس پایه با TenantId برای جداسازی مستأجرها
- Result<T>: الگوی Monad برای مدیریت خطا
- Money: شیء مقداری برای پول (بدون اعشار)
- DomainEvent: سیستم رویدادهای دامنه
- IPaymentProvider: انتزاع درگاه پرداخت

--- Infrastructure ---

- Outbox Pattern: تضمین ارسال رویدادها در یک تراکنش
- Hangfire: زمان‌بندی کارهای پس‌زمینه (یادآوری، بستن دوره حقوقی، رفرش لیدربورد)
- Zarinpal: درگاه پرداخت ایرانی (آداپتور)
- Multi-Tenancy: فیلتر خودکار بر اساس TenantId در تمام کوئری‌ها

================================================================================
                              نتیجه‌گیری
================================================================================

این پروژه یک سیستم جامع مدیریت سالن زیبایی است که:

- فانت‌اند: اپ Flutter چندپلتفرمی با رابط فارسی RTL
- بک‌اند قدیمی: مونولیت ASP.NET Core 9 کاربردی و تولیدی
- بک‌اند جدید: مونولیت مدلار با DDD آماده میکروسرویس‌شدن
- چندمستأجری: پشتیبانی از چند سالن به صورت همزمان
- پرداخت ایرانی: اتصال به زرین‌پال
- پیامک: ارسال از طریق ملی‌پیامک
- امکانات کلیدی: رزرو نوبت، مدیریت خدمات، سیستم وفاداری، موجودی، بازار خدمات
